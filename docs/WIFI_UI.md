## 资源与扫描策略

字体约3.10MB，存于0x610000的3MiB ui_font分区，应用仍占单6MiB factory分区。字体不嵌入应用 rodata，防止本机SDK的PSRAM-XIP复制整套字体。最终实现按字形读取Flash，仅保留16项元数据缓存及1024-byte字形缓冲；复用现有RGB帧缓冲。

串流时跳过界面绘制和触摸设置处理。只有进入设置页才允许手动扫描，不做后台周期扫描。扫描期间暂停串流接入，取消/退出会停止扫描。成功关联并取得IP后保存候选网络；失败不覆盖旧NVS凭据。

早期整字体 rodata 版本使剩余PSRAM从约4.42MB下降到1.34MB，已弃用。独立分区版本恢复了该空间，最终改为按字形读取，避免长期映射整套字体。

## 更新与使用

正常PlatformIO upload会同时写入应用和字库，保留NVS；仅手动写应用适用于字库和分区已经匹配的设备。完整factory从0写入会覆盖中间NVS区域，仅用于首次安装。

电脑配套软件保持打开并选好接收端，S3首页点开始；底栏BACK返回首页。关闭工具栏时从电脑停止。企业Wi-Fi认证不支持；键盘仅ASCII，中文SSID从列表选择。尚未完成长期稳定性、所有特殊字符SSID或全部Windows键盘/滚轮操作验证。
