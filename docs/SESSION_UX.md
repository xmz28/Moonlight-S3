# 连接与操作体验改造（2026-10-30）

本轮围绕“在 S3 选电脑即可使用”统一两端流程。协议升级为 MS3 v3 会话控制，JPEG 帧格式维持 v1；两端需一起更新。未更改 RGB 接线、12 MHz 时序和 JPEG 解码管线。

## 使用流程

1. 电脑软件保持后台运行，关闭设置窗口会收起到托盘；托盘可重新打开或真正退出。开机后台运行是用户可选项，默认不启用。
2. S3 首页保留已配对电脑，显示离线、正在使用、已配对或首次需要配对。离线不会删除授权；IP 变化仍按完整设备身份重新发现。
3. 点电脑后依次显示等待响应、等待 PIN、验证、准备桌面、等待首帧。首次电脑自动弹出 PIN 窗口；拒绝、过期或失败会反馈到 S3，可重试。
4. 返回会取消这一请求。TCP 验证前后检查同一个随机请求 ID；迟到的旧请求不能启动新串流。此检查是业务取消约束，不代表新增流数据加密。
5. 右下角 MENU 始终存在，独立于底栏。打开后暂停画面并释放鼠标，可继续、重连、断开、调整设置或输入文字。断开仅结束投屏，电脑上的应用继续运行。
6. 每台电脑的显示器、分辨率、FPS、质量、底栏、控制权限和输入模式在 S3 设置，保存到 NVS。改变画面设置后重新连接；单指输入模式可在菜单即时切换。

## 单点触摸

- 直接触摸：轻点并松手是左键；移动超过阈值进入左键拖动；停留约 0.6 秒为右键，不同时触发左键。
- 单指触摸板：滑动相对移动指针，轻点左键，长按右键；快速第二次按下并移动可拖动。
- 滚轮使用底栏 SCROLL，再单指上下滑动。没有双指手势要求。
- MENU 提供 Esc、Enter、Tab、Backspace、Ctrl+C/V/A、Alt+Tab。KEYBOARD 打开 S3 本地文字页，目前输入英文、数字与符号，不包含中文输入法；电脑当前焦点接收文字。
- 仅观看模式禁止鼠标、快捷键及文字注入，仍可用本地菜单退出。超时和断开释放按键，恢复需先抬手。

## 配置与诊断

Windows 配置固定在 `%LOCALAPPDATA%\MoonlightS3Host\settings.json`，首次使用新版会迁移程序旁的旧配置并保留原文件。以后更换解压目录不会创建新电脑身份。配置含凭据，不随公开 ZIP 发布。

`diagnostics.log` 在同目录，轮换保存连接阶段、错误和帧率，不记录 PIN、Wi-Fi 密码或长期凭据。S3 本地配置保存失败有屏幕反馈；配对表满时明确提示管理已配对电脑。
